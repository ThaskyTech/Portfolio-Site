MAEA

Market Analysis Execution Agent: an autonomous agent that analyses markets, places trades and edits its own analysis configuration within rules set by its owner.

STATUSIn development
TYPEPersonal project
STACKPython, MetaTrader 5, reinforcement learning
CONTEXTSuccessor to my trading bot

The idea

MAEA analyses markets, places trades through MetaTrader 5 and can edit its own analysis configuration. That freedom sits inside governance rules defined by its owner, so the agent can adapt without being able to override the limits I set.

How it learns

  • A population of evolution-strategy agents explores different behaviours and shares a replay buffer.
  • A central reinforcement-learning agent samples that buffer and models how the market reacts.
  • The system optimises for regime resilience and population diversity. Agents are retired on portfolio depletion, sustained regression or stagnation.

How it's run

I run MAEA as a formal software engineering project: every proposed change is documented against agreed acceptance criteria before it is made.

Where it came from

MAEA evolved from my earlier trading bot for EURUSD and GBPUSD, which used LightGBM models on a multi-timeframe strategy (H4 bias, M15 entries), regime detection, a deterministic risk engine and a high-impact news filter.
